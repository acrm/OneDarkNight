# Game Logic — One Dark Night

## Objective
Survive 5 days without breaking the rules.

## World Rules
1. Never approach scientist neighbor < 15 meters
2. At 01:00 on knock — use salt
3. 02:00–03:00 front door is blocked
4. Prevent parents from breaking rules

## Win/Lose
- **Win**: Survive Day 5 by hiding until 03:00
- **Lose**: Peephole at wrong time, let dad open door, approach scientist, wear bracelet
